# Contributing

Contributions are **welcome** and will be fully **credited**. They are accepted via Pull Requests on [GitHub](https://github.com/jessekoerhuis/laravel-event-flags).

## Pull Requests

- **Follow the Laravel coding standards** - See the [Laravel Coding Style](https://laravel.com/docs/13.x/contributions#coding-style).
- **Run the linter** - Make sure your code passes the linter before submitting a Pull Request.
- **Add tests** - Your PR won't be accepted if it doesn't have tests.
- **Document any change in behaviour** - Make sure the `README.md` and any other relevant documentation are kept up-to-date.
- **Versioning** - Try to follow [SemVer v2.0.0](http://semver.org/).
- **Create feature branches** - Don't ask to pull from your master branch.
- **One Pull Request per feature** - If you want to do more than one thing, send multiple Pull Requests.
- **Send coherent history** - Make sure each individual commit in your Pull Request is meaningful. If you had to make multiple intermediate commits while developing, please [squash them](http://www.git-scm.com/book/en/v2/Git-Tools-Rewriting-History#Changing-Multiple-Commit-Messages) before submitting.

## Running Tests

